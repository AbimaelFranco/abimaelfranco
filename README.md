AHT10 digital sensors over I²C feed a Raspberry Pi 3B acting as processing and server platform, with a custom PCB integrating sensors and actuators (solenoid valves, heating/cooling). A Django + PostgreSQL web dashboard tracks historical readings.<br/><br/>
